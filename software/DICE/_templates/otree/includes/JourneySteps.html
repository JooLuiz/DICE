Journey Steps

A slot is used when it has a feed CSV, an external survey link, or questions JSON. Slots are used in order (1, 2, 3, ...), so don't leave a gap before a slot you want used. Posts whose questionnaire is answered in-app should leave "External survey link" blank and use "Questions (JSON)" instead; posts followed by an outside survey (e.g. Qualtrics) should fill in "External survey link" and leave "Questions (JSON)" blank. "Questionnaire title" is optional: leave it blank to use the session language default.

Questions (JSON) format -- one example of each question type 
[
  {
    "question_type": "single_choice",
    "prompt": "How would you rate this feed overall?",
    "options": [
      {"value": "poor", "label": "Poor"},
      {"value": "good", "label": "Good"},
      {"value": "excellent", "label": "Excellent"}
    ]
  },
  {
    "question_type": "multiple_choice",
    "prompt": "Which topics do you remember seeing?",
    "is_required": false,
    "options": [
      {"value": "travel", "label": "Travel"},
      {"value": "food", "label": "Food"}
    ]
  },
  {
    "question_type": "likert",
    "prompt": "How much did you enjoy this feed?",
    "likert_min": 1,
    "likert_max": 5,
    "likert_min_label": "Not at all",
    "likert_max_label": "Very much"
  },
  {
    "question_type": "open_text",
    "prompt": "What are your first thoughts about this feed?",
    "is_required": false
  }
]

Every question also accepts an optional "question_id" (auto-generated if omitted) and "is_required" (defaults to true).
